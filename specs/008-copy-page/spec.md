# 008 · 복사 페이지

- **상태**: 구현됨
- **관련 스펙**: [002 편집기](../002-scenario-editor/spec.md), [003 그룹과 태그](../003-groups-and-tags/spec.md), [009 채팅 매크로](../009-chat-macros/spec.md)
- **최근 수정**: 2026-10-21

## 목적

세션 진행 중에 쓰는 화면. 시나리오 카드와 채팅 매크로를 **눌러서 바로 복사**해 CCFOLIA·Roll20 채팅에 붙여넣는다.
편집 도구는 보이지 않고 복사에만 집중한다.

## 사용자 시나리오

1. 편집하다 「복사 페이지」를 누르면 커서가 있던 줄의 카드부터 보인다. 카드를 차례로 눌러 붙여넣고, 끝나면 Esc로 편집으로 돌아간다.
2. 판정 매크로를 눌러 복사하고, 핸드아웃 카드를 눌러 편지 전체를 붙여넣는다.

## 기능 요구사항

- **FR-001** 왼쪽 메뉴의 「복사」나 편집 페이지의 「복사 페이지」로 연다. **Esc로 직전 편집 페이지에 돌아간다** (입력칸에 있을 때 Esc는 입력칸만 빠져나온다).
- **FR-002** 복사 페이지에는 시나리오 패널과 채팅 매크로 패널만 있다.
- **FR-003** **카드 자체를 누르면 복사**된다. 카드 안의 버튼(그림 확대 등)은 복사하지 않고, 글자를 드래그해 고르는 중이면 복사하지 않는다.
- **FR-004** 복사한 카드는 잠깐 「복사됨」을 보이고 이후 흐리게 표시된다. 「사용 표시 지우기」로 되돌린다.
- **FR-005** 시나리오 패널: 집합 선택·이전/다음(←→), ↑↓로 카드 고르기, Enter로 복사, 복사하면 다음 카드로 넘어간다 (GM 정보 그룹은 건너뜀). 「집합 전체 복사」(GM 정보 제외).
- **FR-006** **열 때 편집기 커서가 있던 줄의 카드가 선택되고 화면 가운데로 스크롤된다.**
- **FR-007** 카드에는 화자·GM 메모가 보이지만 복사되지 않는다. 그림 카드는 그림을 복사한다.
- **FR-008** 매크로 패널 아래에 「핸드아웃」 태그 그룹 모음을 둔다 (→ 003 FR-030).
- **FR-009** 패널 배치: 시나리오/매크로 좌우·상하 4가지, 경계를 끌어 크기 조절, 패널 하나 숨기기. 설정은 저장된다.
- **FR-010** 상단에 항상 위 고정 핀 (→ 010).
- **FR-011** **따옴표 빼고 복사**: 시나리오 패널 상단의 스위치를 켜면, 줄 전체가 따옴표 한 쌍(`"…"`, `“…”`, `「…」`, `『…』`, `'…'`, `‘…’`)으로 감싸인 대사를 복사할 때 바깥 따옴표를 뺀다. 따옴표 뒤에 글이 더 이어지는 줄(`"안녕." 그가 말했다.`)은 그대로 복사한다. 카드에 보이는 글은 바뀌지 않는다. 설정은 저장된다.
- **FR-012** **집합마다 보던 위치 기억**: 집합을 바꿨다가(←→, 이전/다음 버튼, 집합 고르기) 다시 돌아오면 그 집합에서 마지막으로 보던 스크롤 위치와 선택한 카드로 돌아간다. 처음 여는 집합은 맨 위에서 시작한다. (복사 페이지를 열 때는 FR-006이 우선한다.)

## 수용 기준

- **AC-001** (FR-006) 80줄 집합에서 59번째 줄에 커서를 두고 복사 페이지를 열면 59번 카드가 선택되어 화면에 보인다.
- **AC-002** (FR-001) Esc를 누르면 편집 페이지의 같은 집합으로 돌아온다.
- **AC-003** (FR-003) 카드를 누르면 클립보드에 그 줄의(치환된) 글이 들어간다.
- **AC-004** (FR-011) 스위치를 켜고 `“여기서 뭘 하는 거지?”` 카드를 누르면 클립보드에 `여기서 뭘 하는 거지?`가 들어간다. `"안녕." 그가 말했다.`는 그대로 들어간다. 끄면 따옴표째 들어간다.
- **AC-005** (FR-012) 3번 집합 40번째 카드까지 내려가 → 2번 집합으로 가서 위로 스크롤 → 다시 3번 집합으로 오면 40번째 카드가 선택된 채 같은 위치가 보인다.

## 범위 밖

- 그룹 카드·핸드아웃 모음·「집합 전체 복사」·내보내기의 따옴표 빼기 — 대사 카드 한 줄 복사에만 적용한다 (결정 기록).
- 집합마다 보던 위치를 세이브에 넣기 — 앱이 켜져 있는 동안만 기억한다.
