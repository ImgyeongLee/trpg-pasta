# 004 · 이름 치환·조사 교정

- **상태**: 구현됨
- **관련 TASK**: TASK 1 (시나리오 준비)
- **관련 스펙**: [002 편집기](../002-scenario-editor/spec.md), [007 내보내기](../007-export/spec.md), [008 복사 페이지](../008-copy-page/spec.md)
- **최근 수정**: 2026-10-19

## 목적

시나리오 속 「탐사자」, 「PC」, 「KPC」, 「PC1」 같은 자리를 실제 캐릭터 이름으로 바꿔 붙여넣는다.
이름이 바뀌면 뒤의 조사(은/는, 이/가, 을/를, 으로/로, 아/야 …)도 받침에 맞게 고친다.

## 사용자 시나리오

1. 이름 치환 패널에 `탐사자 → 민준`, `KPC → 하늘`을 넣으면, 편집기 줄 아래에 바뀐 문장이 미리 보이고, 복사 페이지에서는 바뀐 문장이 복사된다.

## 기능 요구사항

- **FR-001** 규칙 = 라벨 → 이름. 기본 라벨은 탐사자·PC·KPC이고, PC1 같은 라벨을 더할 수 있다.
- **FR-002** 글 속에서 쓰인 라벨과 횟수를 찾아 보여준다 (규칙에 없으면 추가 버튼).
- **FR-003** 조사를 이름의 끝소리에 맞게 고친다: `탐사자는` → `민준은`, `KPC야,` → `하늘아,`, `PC은(는)` → `민준은`.
- **FR-004** 끝소리 판단은 규칙마다 고른다: 자동(이름 끝 글자), 받침 있음, 받침 없음, ㄹ 받침(으로 대신 로).
- **FR-005** 치환 결과는 편집기 미리보기, 복사 페이지, 그룹 카드, 텍스트 내보내기(켰을 때)에 쓰인다. 원문은 바뀌지 않는다.
- **FR-006** 규칙은 다음 실행에도 남고 세이브에도 들어간다.

## 비기능 요구사항

- **NFR-001** 치환은 Rust에서 하고, 글·규칙이 바뀌면 잠깐(약 200ms) 기다렸다 한 번에 다시 계산한다.

## 수용 기준

- **AC-001** (FR-003) 규칙 `탐사자 → 민준`에서 `탐사자는 문을 연다.` → `민준은 문을 연다.`
- **AC-002** (FR-004) `ㄹ 받침` 이름 「하늘」은 `탐사자로` → `하늘로`.
- **AC-003** (FR-005) 핸드아웃 그룹 안의 라벨도 복사할 때 바뀐다.
