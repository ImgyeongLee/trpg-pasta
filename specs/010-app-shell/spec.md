# 010 · 앱 공통

- **상태**: 구현됨
- **최근 수정**: 2026-10-19

## 목적

여러 GM 도구를 담는 앱 껍데기. 세션 중 다른 창(CCFOLIA)과 함께 쓰기 좋게 하고, 화면 설정·글꼴·색을 일관되게 유지한다.

## 기능 요구사항

- **FR-001** 왼쪽 메뉴로 도구를 바꾼다: 시나리오 준비, 채팅 매크로, 「복사」(복사 페이지). 앞으로 도구가 더 붙는다.
- **FR-002** **항상 위에 고정**: 핀 버튼(왼쪽 메뉴 아래, 복사 페이지 상단)을 켜면 다른 창을 눌러도 이 창이 가려지지 않는다. 설정은 저장된다.
- **FR-003** 화면 배치(패널 열림, 좌우 위치, 크기, 복사 페이지 배치)는 저장되어 다음 실행에도 유지된다.
- **FR-004** 색 테마는 OS 설정(라이트/다크)을 따른다. 포인트 색은 초록.
- **FR-005** 글꼴은 Pretendard로 고정한다. 앱에 넣은 가변 글꼴을 쓰고, 화면에 나온 글자 범위의 조각만 읽는다. 인터넷이 없어도 같다.
- **FR-006** 확인 창(저장 여부 등)은 앱 자체 대화상자로 띄운다.
- **FR-007** 창 어디에 파일을 놓아도 브라우저 기본 동작(파일 열기)으로 화면이 바뀌지 않는다.
- **FR-008** 앱 이름은 **TRPG Pasta**. 아이콘은 연두색 바탕에 종이와 펜촉 (글쓰기 앱 느낌). 원본은 `src-tauri/icons/logo.svg`, 크기별 파일은 `npx tauri icon`으로 만든다.

## 비기능 요구사항

- **NFR-001** 글꼴 때문에 시작이 느려지지 않는다 (유니코드 범위별 92개 조각 중 쓰는 것만 읽음).
- **NFR-002** 창 기본 크기 1280×840.

## 수용 기준

- **AC-001** (FR-002) 핀을 켜고 다른 앱 창을 누르면 이 창이 위에 남는다. 앱을 다시 켜도 켜져 있다.
- **AC-002** (FR-005) 글꼴 목록에 「Pretendard Variable」이 쓰이고, 첫 화면에서 읽은 글꼴 조각이 일부뿐이다.
