# 007 · 내보내기

- **상태**: 구현됨
- **관련 스펙**: [003 그룹과 태그](../003-groups-and-tags/spec.md), [004 이름 치환](../004-name-substitution/spec.md)
- **최근 수정**: 2026-10-19

## 목적

정리가 끝난 시나리오를 텍스트 파일로, 잘라낸 그림을 이미지 파일로 저장해 다른 곳(세션 툴, 메모장)에서 쓴다.

## 기능 요구사항

### 텍스트

- **FR-001** 상단 「내보내기」 → 「텍스트 파일로 저장…」. 한 줄에 한 블록, 그룹은 앞뒤 빈 줄을 두고 여러 줄 그대로.
- **FR-002** 그림 자리는 `[그림 03 · 12쪽]`처럼 표시한다 (그림 파일과 같은 번호). 텍스트 원본의 `[이미지: …]`는 설명을 살린다.
- **FR-003** 선택 사항:
  - 이름 치환 적용 (치환 규칙이 있으면 기본 켬)
  - GM 메모·정보 포함 — 메모는 줄 아래 `    ※ 메모`, GM 정보 그룹은 줄마다 `※ GM: `, 태그·제목이 있는 그룹은 위에 `※ 태그: 제목`. 끄면 GM 정보 그룹은 빠진다.
  - 대사 앞에 화자 붙이기 (`KPC: "가자."`)
  - 제목 앞에 빈 줄
- **FR-004** 아직 정리 중이면 「정리된 부분까지만 들어간다」고 알린다.

### 그림

- **FR-010** 「그림 모두 저장」: 고른 폴더에 `그림03_12쪽.png`. 같은 이름이 있으면 덮어쓰지 않고 새 이름을 쓴다.
- **FR-011** 그림 하나는 그림 위의 저장 버튼으로 저장한다.

### 세이브 파일

- **FR-020** 같은 메뉴에서 세이브 파일로 내보낸다 (→ 006).

## 비기능 요구사항

- **NFR-001** 저장 경로는 Rust 대화상자로만 고른다. 파일 이름의 금지 문자를 바꾼다.

## 수용 기준

- **AC-001** (FR-002) 12쪽의 세 번째 그림 자리는 텍스트에 `[그림 03 · 12쪽]`, 그림 파일은 `그림03_12쪽.png`.
- **AC-002** (FR-003) 「GM 메모·정보 포함」을 끄면 GM 정보 그룹의 글이 텍스트에 없다.
