# 009 · 채팅 매크로

- **상태**: 구현됨
- **관련 스펙**: [008 복사 페이지](../008-copy-page/spec.md), [003 그룹과 태그](../003-groups-and-tags/spec.md)
- **최근 수정**: 2026-10-19

## 목적

판정 명령어(`CC<=50 【관찰력】`)나 꾸민 문구(구분선, 장면 전환)를 저장해 두고, 세션 중 버튼 한 번으로 복사한다.
일부를 그때그때 바꿔야 하는 문구는 템플릿 변수로 만든다.

## 사용자 시나리오

1. `{관련} 판정` 매크로에 「듣기」를 넣고 카드를 누르면 `듣기 판정`이 복사된다.
2. `CC<={수치} 【{기능:관찰력/듣기}】`에서 수치를 넣고 「관찰력」 버튼을 누르면 바로 복사된다.

## 기능 요구사항

- **FR-001** 매크로 = 이름 + 본문 + 그룹. 「채팅 매크로」 페이지에서 그룹별로 보여준다.
- **FR-002** 템플릿 변수: `{이름}`은 입력칸, `{이름:선택1/선택2}`는 선택 버튼. 같은 이름이 여러 번 나오면 같은 값으로 채운다.
- **FR-003** 선택 버튼을 누르면 값이 정해지고, 다른 칸이 모두 채워져 있으면 바로 복사한다.
- **FR-004** 카드를 누르면 완성된 문구가 복사된다 (입력칸·선택 버튼은 그대로 동작).
- **FR-005** 마지막으로 쓴 변수 값을 기억한다.
- **FR-006** 「편집」을 켜면 매크로 추가·수정·순서 변경(앞으로/뒤로)·삭제, 그룹 추가·이름 바꾸기·삭제(두 번 누르기, 안의 매크로 수 표시)를 한다.
- **FR-007** 앱 데이터 폴더의 `macros.json`에 바로 저장한다 (시나리오 세이브와 별개, 모든 시나리오에서 공유).
- **FR-008** 처음 실행하면 기본 매크로(판정, 텍스트 꾸미기)를 넣어 둔다.
- **FR-009** 매크로 목록 아래에 시나리오의 「핸드아웃」 태그 그룹을 모아 보여준다 (→ 003 FR-030).

## 수용 기준

- **AC-001** (FR-002, FR-004) 본문 `{관련} 판정`, 입력 「듣기」 → 카드 클릭 → 클립보드 `듣기 판정`.
- **AC-002** (FR-005) 앱을 다시 켜도 마지막 입력값이 남아 있다.

## 범위 밖

- 매크로를 시나리오 세이브에 넣기 — 매크로는 모든 시나리오에서 같이 쓴다.
