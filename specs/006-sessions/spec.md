# 006 · 세이브

- **상태**: 구현됨
- **관련 스펙**: [001 불러오기](../001-scenario-import/spec.md), [003 그룹과 태그](../003-groups-and-tags/spec.md)
- **최근 수정**: 2026-10-21

## 목적

시나리오 정리는 한 번에 끝나지 않는다. 하던 작업을 저장했다가 이어서 하고, 다른 컴퓨터로 옮길 수 있게 한다.
세이브는 작아야 한다.

## 사용자 시나리오

1. 정리하다 ⌘S로 저장하고 앱을 끈다. 다음에 첫 화면 「최근 작업」에서 이어서 한다.
2. 세이브 파일로 내보내 다른 컴퓨터에서 연다. 같은 PDF를 고르면 그림과 원본 보기가 돌아온다.

## 기능 요구사항

- **FR-001** 상단 「저장」 또는 ⌘/Ctrl+S로 앱 안에 저장한다. **자동 저장은 하지 않는다.**
- **FR-002** 마지막 저장 뒤 바뀐 것이 있으면 상단에 「저장 안 된 변경 있음」을 보여준다.
- **FR-003** 저장 안 된 채로 창을 닫거나 「새 시나리오」를 누르면 「저장하고 닫기 / 저장하지 않음 / 취소」를 묻는다.
- **FR-004** 첫 화면 「최근 작업」: 이름, 줄 수, 집합 수, 크기, 저장한 때를 보여주고, 눌러서 이어 하고, 두 번 눌러 지운다.
- **FR-005** 세이브 파일(`.trpgsave`)로 내보내고 연다.
- **FR-006** 세이브에는 원본 PDF·그림을 넣지 않는다. 그림은 PDF 속 위치만, PDF는 지문(SHA-256·크기)만 기록한다. 텍스트 원본은 글을 넣는다.
- **FR-007** PDF 작업 세이브를 열면 「원본 PDF 연결」을 안내하고, 같은 PDF(지문 일치)를 고르면 그림과 원본 보기가 돌아온다. 다른 PDF면 확인 후에만 연결한다.
- **FR-008** 세이브에는 집합·블록(글·종류·경고·쪽·메모·화자·복사함·그룹 제목·태그), 이름 치환 규칙, 정리 옵션, 쓴 사용자 태그가 들어간다.
- **FR-009** 예전 형식의 세이브도 열린다 (변환 규칙은 [architecture.md](../architecture.md#세이브-형식-savefile-version-1)).
- **FR-010** **작업 제목 바꾸기**: 편집 페이지 윗줄의 제목(처음에는 불러온 파일 이름)을 두 번 누르거나 연필 버튼으로 바꾼다. Enter로 정하고 Esc로 취소, 빈 이름은 받지 않는다. 원본 파일 이름은 바뀌지 않는다. 바꾼 제목은 「저장 안 된 변경」이 되고, 저장하면 「최근 작업」 이름·세이브 파일 내보내기·텍스트/그림 내보내기 파일 이름에 쓰인다.

## 비기능 요구사항

- **NFR-001** gzip 압축 JSON, 짧은 키, 기본값은 생략한다.
- **NFR-002** 파일 쓰기는 임시 파일 후 바꾸기(원자적). 세이브 id·이름은 경로 조작을 막는다. 크기 상한 256MB.

## 수용 기준

- **AC-001** (FR-003) 글을 고친 뒤 창을 닫으면 저장 여부를 묻는다.
- **AC-002** (FR-006) 그림이 많은 PDF 작업의 세이브가 PDF보다 훨씬 작다.
- **AC-003** (FR-007) 세이브를 열고 같은 PDF를 고르면 그림이 다시 보인다.
- **AC-004** (FR-010) `scenario_v3.pdf`를 불러와 제목을 「안개 속의 마을」로 바꾸고 저장하면 「최근 작업」에 「안개 속의 마을」로 나오고, 세이브 파일 내보내기 기본 이름이 `안개 속의 마을.trpgsave`다.

## 범위 밖

- 「최근 작업」 목록에서 이름 바꾸기 — 편집 페이지 윗줄에서만 바꾼다 (결정 기록).
