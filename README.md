# TRPG Pasta

CCFOLIA, Roll20 등으로 TRPG를 진행하는 게임 매니저(GM)를 위한 데스크탑 도구 모음입니다.
Rust + Tauri 2 + Svelte 5 + Vite로 만들었습니다.

## 기능

### 시나리오 준비

- PDF / 텍스트(.txt, .md, 붙여넣기) / **구글 문서 공유 링크** 시나리오를 문장 단위로 한 줄씩 정리
  - 구글 문서: 「공유 → 링크가 있는 모든 사용자 (뷰어)」로 바꾼 뒤 링크를 붙여넣거나 끌어다 놓기 (로그인 불필요, 정리는 글자만)
    - 원본 보기에서는 같은 문서를 PDF로 받아 **구글 문서 모양 그대로**(서식·그림) 보여주고 목록과 연동. 「텍스트」 보기, 「브라우저에서 열기」도 가능
  - `...`, `......`, `…` 같은 말줄임표는 문장 끝으로 보지 않음 (옵션으로 말줄임표 뒤에서 나누기 가능)
  - `"대사"`, `「대사」`는 안쪽에서 나누지 않고 **대사**로 분류 (`"…"라고 말했다`처럼 이어지는 문장은 유지)
  - 소수점(3.5%), 목록 번호(1. 도입), 판정식(SAN 0/1d3) 등은 문장 끝으로 보지 않음
  - 쪽수와 반복되는 머리글/바닥글 제거, 단어 중간에서 바뀐 줄은 자동으로 붙임
  - 중간의 그림은 잘라내서 **그림** 블록으로 표시 (그림 복사 가능). 선·상자로 그린 배치도·지도도 그림으로 잡고, 그 안의 라벨은 문장에 섞지 않음 (글이 빽빽한 표는 글로 둠)
- 긴 PDF는 몇 쪽씩 처리해 첫 집합부터 바로 고칠 수 있음. 한 집합은 100~250줄 안팎으로 자동으로 나눔 (제목 줄·쪽이 바뀌는 곳 우선)
- 편집 화면: **일반 에디터처럼** 고친다. **한 줄 = 복사 페이지의 카드 하나** (Enter로 나누면 카드도 나뉨, 여러 줄 붙여넣기 가능)
  - 줄 끝 태그(대사·제목·경고·화자), GM 메모는 줄 아래 노란 칸 (복사 안 됨)
  - 「현재 줄」 막대에서 종류·화자·메모 변경, 여러 줄을 고르면 그룹으로 묶기·GM 정보로 묶기·삭제
  - GM 메모는 Enter로 저장 (줄바꿈은 Shift+Enter)
  - **그룹**: 여러 줄을 골라 「그룹으로 묶기」를 누르면 카드 하나로 묶임. 카드 안의 Enter는 줄바꿈일 뿐이고, 카드를 둘로 나누려면 「나누기」(⌘/Ctrl+Enter). 「줄로 풀기」로 다시 한 줄씩
  - **그룹 태그**: 프리셋 핸드아웃(노랑)·성공 판정(연두)·실패 판정(분홍)·GM 정보(파랑, 복사·내보내기에서 빠짐) + 직접 만든 태그(이름·색). 카드가 태그 색으로 칠해짐. 만든 태그는 이 컴퓨터에 저장되고, 세이브 파일에도 함께 들어감
  - 커서 줄은 초록 띠와 줄 번호로 표시, ⌘/Ctrl+Enter 다음 줄, ⌘⇧G 그룹으로 묶기, ⌘⇧M 메모, ⌘Z 되돌리기 (지운 줄의 메모·태그도 함께 돌아옴)
  - 줄 찾기 칩(대사·GM 정보·경고·그림·그룹·메모): 누르면 다음 해당 줄로 이동
  - 그림은 줄 사이에 그대로 보이고, 실수로 다른 줄과 합쳐지지 않게 보호 (그림을 눌러 고른 뒤 「그림 지우기」)
- **원본 보기**: 원본 PDF(또는 텍스트)를 문장 목록 옆에 띄워 비교하며 정리
  - 목록에서 줄을 고르면 원본의 그 쪽으로 이동하고 문장을 형광펜으로 표시 (쪽을 넘어가는 문장도 표시)
  - 원본에서 글자를 누르면 목록의 그 줄로 이동
  - **그림 자르기**: 자동으로 못 잡은 그림은 원본에서 영역을 끌어 현재 줄 뒤에 그림으로 넣음 (세이브에도 위치가 남음)
  - 쪽 이동, 확대/축소, 목록 왼쪽/오른쪽 배치, 경계를 끌어 너비 조절
- **내보내기** (상단 「내보내기」)
  - 텍스트 파일: 한 줄에 한 문장, 그림 자리는 `[그림 03 · 12쪽]` 표시. 이름 치환·GM 메모·제목 앞 빈 줄 선택
  - 그림 모두 저장: 고른 폴더에 `그림03_12쪽.png` (텍스트 표시와 같은 번호, 같은 이름이 있으면 덮어쓰지 않음)
  - 그림 하나만: 그림 위의 저장 버튼
- 집합 목록: 이름 바꾸기(이름 두 번 누르기·연필), 「＋ 새 집합」, 현재 줄 막대의 「여기서 새 집합」, 「아래 집합과 합치기」, 집합 삭제 — 모두 되돌리기 가능
- 집합 목록·이름 치환 패널은 상단 버튼으로 접고 펼 수 있고, 좌우 위치를 바꿀 수 있음
- 이름 치환: `탐사자`, `PC`, `KPC`, `PC1` 등 라벨 → 캐릭터 이름, 조사를 받침에 맞게 교정
  (`탐사자는` → `민준은`, `KPC야,` → `하늘아,`, `PC은(는)` → `민준은`)

### 세이브

- 상단 「저장」 또는 **⌘/Ctrl+S**로 앱 안에 저장 (자동 저장은 하지 않음). 저장 안 된 변경은 상단에 표시
- 저장 안 된 채로 창을 닫거나 「새 시나리오」를 누르면 「저장하고 닫기 / 저장하지 않음 / 취소」를 물어봄
- 첫 화면 「최근 작업」에서 이어서 하기
- 세이브 파일(`.trpgsave`, gzip 압축 JSON)로 내보내기/열기 — 다른 컴퓨터로 옮기거나 보관용
- **경량화**: 원본 PDF와 그림은 넣지 않고 그림의 PDF 속 위치만 기록. 세이브를 연 뒤 같은 PDF를 고르면(지문 SHA-256으로 확인) 그림과 원본 보기가 돌아옴

### 복사 페이지

- 게임 진행용 별도 페이지. 왼쪽 메뉴의 「복사」나 시나리오 준비의 「복사 페이지」로 열고, **Esc**로 직전 편집 페이지에 돌아감
- 시나리오 패널 + 채팅 매크로 패널: **카드를 누르면 바로 복사** (GM 메모는 보이기만 하고 복사되지 않음)
- 매크로 아래에 핸드아웃 모음(「핸드아웃」 태그 그룹만): 누르면 그룹 전체(여러 줄)가 한 번에 복사
- 복사 페이지를 열면 편집기 커서가 있던 줄의 카드부터 시작
- ↑↓ 고르기 · Enter 복사 · ←→ 집합 이동, 복사한 줄은 흐리게 표시
- 패널 배치(시나리오/매크로 좌우·상하) 선택, 경계를 끌어 크기 조절, 패널 숨기기 — 설정은 저장됨

### 채팅 매크로

- 판정 명령어, 텍스트 꾸미기 문구를 저장해 두고 버튼 한 번으로 복사
- 템플릿 변수: `{관련} 판정` → 입력칸, `CC<={수치} 【{기능:관찰력/듣기}】` → 입력칸 + 선택 버튼
  (선택 버튼을 누르면 다른 칸이 채워져 있을 때 바로 복사)
- 그룹으로 정리, 편집 모드에서 추가·수정·순서 변경·삭제, 마지막 입력값 기억
- 카드를 누르면 복사 (입력칸·선택 버튼은 그대로 동작)
- 앱 데이터 폴더의 `macros.json`에 자동 저장

### 공통

- **항상 위에 고정**: 왼쪽 메뉴 아래(또는 복사 페이지 상단)의 핀 버튼. 켜면 CCFOLIA 등 다른 창을 눌러도 이 창이 뒤로 가려지지 않음 (설정 저장)

## 개발

Node.js 22 이상과 Rust(stable)가 필요합니다.

```bash
nvm use            # .nvmrc (Node 22)
npm install
npm run tauri dev  # 개발 서버: http://127.0.0.1:1440
```

- `npm run check` — Svelte/TypeScript 타입 검사
- `cd src-tauri && cargo test` — 문장 분리·조사 교정 등 Rust 단위 테스트
- `npm run tauri build` — 배포용 빌드

개발은 스펙 주도(SDD)로 합니다. 기능을 만들거나 바꾸기 전에 [specs/](specs/README.md)의 헌법과 기능 스펙을 먼저 봅니다.
